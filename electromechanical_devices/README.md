# Theory of Electromechanical Devices — collection of main results

`electromechanical_devices.tex`, compiled to `electromechanical_devices.pdf`. Lecture notes
summarizing the electromagnetic background needed for the machine and actuator models used
in the control notes.

## Contents

1. **Review of Maxwell's equations** — Maxwell's equations (constitutive relations,
   integral form, boundary conditions, force and torque), potentials, quasi-static theory,
   static theory.
2. **Field Analysis** — magnetostatic analysis (vector potential, force and torque, Maxwell
   stress tensor, energy), the current model, the charge model (force, torque), magnetic
   circuit analysis (current sources, magnet sources).
3. **Electromechanical devices** — device basics, quasi-static field theory in stationary
   and moving reference frames, electrical equations (stationary circuits, moving coils),
   energy analysis, solenoid actuator example.

Figures are in `figures/`.
